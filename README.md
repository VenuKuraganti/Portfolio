# Venu Gopala Krishna - Personal Portfolio

A modern and responsive personal portfolio website built with React.js to showcase my skills, projects, learning journey, and interests in technology.

## 🌐 Portfolio

This portfolio is designed to present my profile, technical skills, strengths, projects, and contact information through a clean and interactive interface.

## ✨ Features

- 🎨 Modern dark-themed UI
- 📱 Responsive design for desktop, tablet, and mobile
- 🏠 Hero section with personal introduction
- 👨‍💻 About section
- 🛠️ Technical skills section
- 💪 Strengths section
- 🚀 Projects showcase
- 📩 Contact form with Web3Forms
- 📄 Resume view/download
- 🔗 Social media links
- ✨ Interactive animations and effects
- 🖱️ Custom cursor animation

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Tools & Services
- Vite
- Git
- GitHub
- Web3Forms
